## 🛡 Технологический стек

Я подбираю инструменты под задачу: где-то важна скорость запуска (зарубежные облака), а где-то — соответствие российскому законодательству о данных (отечественные сервисы).

### 🌐 Frontend (То, что видит пользователь)
*   **TypeScript:** Строгий язык программирования. Помогает избегать ошибок еще на этапе написания кода, делая систему стабильной.
*   **React & Next.js:** Современные стандарты веб-разработки. Обеспечивают мгновенную работу интерфейса и отличную видимость сайта в поисковиках (SEO).
*   **Tailwind CSS:** Инструмент для быстрой и красивой верстки. Позволяет создавать адаптивный дизайн, который идеально смотрится на любом экране.

### ⚙️ Backend & Data (Серверная часть и данные)
*   **Node.js:** «Двигатель» системы. Обрабатывает логику, отправляет уведомления и связывает все части проекта.
*   **SQL & Prisma:** Надежное хранение информации. SQL — это язык баз данных, а Prisma — удобный инструмент для управления ими без лишней сложности.
*   **Python:** Универсальный язык для сложных задач: глубокой аналитики, парсинга данных или написания специфических скриптов автоматизации.

### ☁️ Хостинг и Облака (Где живет проект)
*   **Vercel / Supabase (Зарубежные):** Лидеры рынка для быстрого развертывания. Идеальны для стартапов и проектов, ориентированных на глобальную аудиторию.
*   **VK Cloud / Yandex Cloud (Российские):** Мощные отечественные платформы. Используются, если важно хранить данные внутри РФ (152-ФЗ) или нужна тесная интеграция с экосистемой VK/Яндекс.

### 📦 Инфраструктура и Безопасность
*   **Git & GitHub:** Система контроля версий. Гарантирует, что ни одна строчка кода не потеряется, и позволяет легко возвращаться к рабочим версиям.
*   **Docker:** Технология упаковки проектов. Позволяет перенести систему на любой сервер и быть уверенным, что она запустится без сбоев.
